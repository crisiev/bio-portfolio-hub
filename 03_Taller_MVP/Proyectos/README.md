## 📐 1. Convención de Organización

- **Un subfolder por producto:** `Proyectos/<nombre-proyecto>/`.
- **Repo aparte en GitHub:** Cada proyecto es un repositorio en GitHub para que su historial de commits certifique tu experiencia.
- **Estructura mínima de un proyecto:**
  - `README.md` — Documentación seria y clara.
  - `src/` o `main.py` — Código fuente tecleado a mano.
  - `requirements.txt` / `environment.yml` — Entorno reproducible.
  - `Dockerfile` — Contenerización.
  - `tests/` — Verificación automatizada.
