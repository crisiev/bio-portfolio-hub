# 📖 Aprendizaje — tus notas escritas a mano

Aquí vives tú, no el LLM. Un subfolder por dominio. La regla (de `AGENTS.md`): **el LLM te guía; tú escribes cada nota y cada línea de código.** Escribir con tus palabras es lo que convierte "vi un tutorial" en "lo domino".

## Subcarpetas

- **`Linux/`** — comandos, permisos, procesos, SSH, bash scripting, administración. Tu oficina diaria.
- **`Python/`** — fundamentos, pandas, Biopython, FastAPI, tests.
- **`Git/`** — versionado, ramas, flujo colaborativo, GitHub.
- **`SQL/`** — modelo relacional, consultas, diseño de esquemas.
- **`Bioinformatica/`** — NGS, formatos, pipelines, estadística aplicada, IA/foundation models.

## Cómo usar cada nota (sugerencia)

Para cada tema que estudies, crea `AAAA-MM-DD_tema.md` y escribe:
1. **Qué es** (en tus palabras, no copiado).
2. **Cómo se usa** (comando/código que TÚ tecleaste y probaste).
3. **Un ejemplo propio** (no el del tutorial).
4. **Dónde me atoré** y cómo lo resolví.

> Estas notas + tus commits son evidencia de aprendizaje real y fechado. Conéctalas con tu `Bitacora/`.
