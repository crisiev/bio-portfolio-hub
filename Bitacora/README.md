# 📓 Bitácora de práctica — empleoBio

Registro fechado de todo lo que practico en serio. Su función es doble:

1. **Aprender con intención.** Escribir qué hice y qué aprendí fija el conocimiento mejor que solo hacerlo.
2. **Experiencia comprobable.** Si un reclutador me pide "experiencia demostrable", esta bitácora + mi historial de commits en GitHub son mi respaldo con fechas reales.

## ⚠️ Lo más importante: la fecha real la da Git, no el archivo

Un archivo de texto se puede editar y falsear. Lo que **nadie puede falsear** es un historial de commits de Git: cada commit lleva una fecha firmada. Por eso la regla de oro es:

> **Cada día que practico algo serio → hago al menos un commit.** La bitácora narra; el commit certifica.

Lleva esta carpeta (y todo tu portafolio) en repositorios de GitHub. La combinación *bitácora escrita + commits fechados* es prueba tan sólida como un certificado laboral — a veces más, porque es verificable.

## Cómo usar esta carpeta

- Un archivo por mes: `2026-07.md`, `2026-08.md`, etc.
- Cada día que trabajes, copia el bloque de `_PLANTILLA_dia.md` al inicio del mes actual y rellénalo.
- Sé honesto: registra también los errores. Un error registrado es munición para la pregunta de entrevista "háblame de un fracaso" (tus "cicatrices" de La Campaña).
- Al terminar el día: `git add . && git commit -m "bitacora: <qué hiciste>"`.

## Estructura

```
Bitacora/
├── README.md            ← este archivo
├── _PLANTILLA_dia.md    ← copia este bloque cada día
├── 2026-07.md           ← mes actual
└── 2026-08.md           ← siguiente mes...
```
