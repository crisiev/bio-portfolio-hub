## 🏆 Ganador absoluto: `IDEA-01` Asistente de estadística para tesis

**Por qué este y no otro** (para ambientarte en el contexto y escalar TODO el conocimiento):

1. **Mercado más amplio y cálido de tu campus.** *Toda* facultad hace tesis y la estadística es el cuello de botella más temido → validación y primer usuario que paga más rápidos. En una universidad pública con estratos mixtos, un dolor universal gana.
2. **Te obliga a practicar el stack contratable completo:** Python (scipy/statsmodels) · FastAPI · frontend · Docker · cloud · LLM · base de datos. Es casi tu temario de skills faltantes hecho un solo producto.
3. **Doble propósito empleo:** la estadística ES núcleo de bioinformática (tu materia *Estadística para Bioinformática*). Practicar aquí es practicar para el trabajo.
4. **Plataforma que escala:** empieza con un test → crece a suite de tesis (escritura, gráficos, modo docente institucional). Crecimiento lineal → exponencial.
5. **Ético y sin fricción:** cero riesgo clínico/legal, y el precio no-brainer ($0.99) encaja con tu entorno.

**Runner-up para portafolio de bioinformática puro:** `IDEA-02` Toolkit de biología molecular (más "genómico" en el CV). Si tu prioridad fuera el CV técnico sobre la validación rápida, sería esta. Ambas son válidas — por eso todo está tipado: puedes pivotar.
