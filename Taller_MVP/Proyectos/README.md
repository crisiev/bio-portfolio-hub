## Convención
- Un subfolder por producto: `Proyectos/<nombre-proyecto>/`.
- Cada proyecto es también un **repo aparte en GitHub** (para que su historial de commits cuente como experiencia).
- Estructura mínima de un proyecto (la irás construyendo tú): `README.md`, código (`src/` o `main.py`), `requirements.txt`/`environment.yml`, `Dockerfile`, `tests/`.
