- **🎯 Objetivo del día:** Auditoría forense de gobernanza, setup del entorno virtual bioinformático (`mamba` + `bio-env`) y primera navegación genómica CLI.
- **🛠️ Qué hice:** (1) Auditoría de gobernanza y `CONTRIBUTING.md`. (2) Instalado `Miniforge3` con `mamba` en AlmaLinux WSL, configurados canales `conda-forge` y `bioconda` con `channel_priority: strict`. (3) Creado entorno virtual aislado `bio-env` con Python 3.11, Biopython, pandas, pytest y ruff. (4) Creadas carpetas modulares `data/raw`, `data/processed`, `data/reference`. (5) Descargado dataset genómico `ecoli_test.fasta` (4.5MB, NCBI U00096.3) en `data/raw/` y verificado con `ls -lh` y `head`.
- **💻 Comandos Útiles del Día (Recetario CLI):**
  ```bash
  # 1. Descargar e instalar Miniforge3 (Mamba nativo en Linux/WSL)
  curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh"
  bash Miniforge3-Linux-x86_64.sh
  source ~/.bashrc

  # 2. Configurar canales de bioconda con prioridad estricta (evita ABI mismatch)
  conda config --add channels defaults
  conda config --add channels bioconda
  conda config --add channels conda-forge
  conda config --set channel_priority strict

  # 3. Crear y activar entorno virtual aislado para bioinformática
  mamba create -n bio-env python=3.11 biopython pandas pytest ruff -y
  mamba activate bio-env

  # 4. Crear estructura modular de directorios (CONVENCIONES.md)
  mkdir -p data/raw data/processed data/reference

  # 5. Descargar dataset FASTA de NCBI siguiendo redirecciones HTTP (-L)
  curl -L -o data/raw/ecoli_test.fasta "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=U00096.3&rettype=fasta&retmode=text"

  # 6. Verificar peso del archivo e inspeccionar cabecera FASTA
  ls -lh data/raw/ecoli_test.fasta
  head -n 10 data/raw/ecoli_test.fasta

  # 7. Limpieza de archivos temporales hacia carpeta de archivación
  mkdir -p _archivacion && mv Miniforge3-Linux-x86_64.sh _archivacion/

  # 8. Staging quirúrgico, preservación de carpeta con .gitkeep y commit/push en Git
  git add -f _archivacion/.gitkeep
  git add AGENTS.md PLAN_MAESTRO.md 02_Campana/02_Registro_de_Campana_Ejercicios.md 04_Bitacora/2026-07.md
  git commit -m "docs(governance): complete Day 1 (35 XP / $150 USD), add _archivacion/.gitkeep and update value pricing rules"
  git push origin main
  ```
- **📚 Qué aprendí:** La prioridad estricta de canales en Conda previene conflictos entre paquetes del sistema y Biopython. `curl -L` es indispensable para seguir redirecciones HTTP en NCBI E-utilities.
- **🩹 Cicatrices (errores):** Advertencia de prioridad de canal al instalar Biopython sin `channel_priority: strict`; resuelto reordenando `.condarc`.
- **🔗 Evidencia:** Archivo `data/raw/ecoli_test.fasta` (4.5MB), entorno `bio-env` activo en AlmaLinux. 35 XP acumulados.
- **➡️ Siguiente paso:** Arrancar Semana 1 Día 2 (`R1-XUB-004`: Inspeccionar FASTQ gigante sin abrirlo + `R1-XUB-005`: grep/awk).
