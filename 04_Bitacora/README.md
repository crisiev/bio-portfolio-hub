## 🔒 1. Regla de Fecha Real (Git Manda)

> [!CAUTION]
> Un archivo de texto se puede editar. Lo que **nadie puede falsear** es un historial de commits de Git: cada commit lleva una fecha firmada.  
> **Cada día que practico algo serio → hago al menos un commit.** La bitácora narra; el commit certifica.

Lleva esta carpeta en repositorios de GitHub. La combinación *bitácora escrita + commits fechados* es prueba más sólida que un certificado laboral.

## 📝 2. Cómo Usar Esta Carpeta

- **Un archivo por mes:** `2026-07.md`, `2026-08.md`, etc.
- **Cada día que trabajes:** Copia el bloque de `_PLANTILLA_dia.md` al inicio del mes actual y rellénalo.
- **Sé honesto:** Registra también los errores. Un error registrado es munición para la pregunta de entrevista *"háblame de un fracaso"*.
- **Al terminar el día:** `git add 04_Bitacora/2026-07.md && git commit -m "docs(bitacora): update daily log"`.
