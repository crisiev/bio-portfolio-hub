# 📜 Scripts de Utilidad & Automatización

> [!NOTE]
> Scripts transversales de automatización, descarga de datos genómicos (`E-utilities`/NCBI) y utilidades de entorno.

---

## 🛠️ Convención de Scripts

- **`setup_environment.sh`**: Script para inicialización de Conda/mamba y dependencias.
- **`fetch_ncbi_data.py`**: Utilidad Python para consultar e-utilities y poblar `data/raw/`.
- **`format_check.sh`**: Verificador de linting y formateo de Markdown/Python.
